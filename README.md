## ⚡ The Problem: LLM "Regression to the Mean"

Standard Large Language Models default to predictable, low-craft web interfaces:
- ❌ Centered purple-to-indigo gradient hero banners (`linear-gradient(to right, #6366f1, #a855f7)`).
- ❌ Generic 3-card identical rectangular grids with circular placeholder icons.
- ❌ Hollow marketing buzzwords (*"Empower your workflow with intelligent solutions"*).
- ❌ Dead UI: fake buttons with no hover states, static sliders, non-functional search inputs.
- ❌ Harsh, flat single-layer drop shadows (`box-shadow: 0 4px 10px rgba(0,0,0,0.3)`).
- ❌ Uncalibrated contrast failing basic accessibility standards.

This repository provides the **antidote**: an operational AI Skill rulebook paired with **22 production-grade reference implementations** spanning pure Three.js WebGL spatial engines, tactile button physics, asymmetrical Bento architectures, and mathematical category theory laboratories.

To achieve agency-grade perfection on every project, follow this 4-step sequence:

## 📋 Pre-Delivery 10-Point "Anti-Slop" Audit

Before delivering any frontend codebase, verify that:
1. **Layout Asymmetry:** No identical 3-box card rows. Employs hierarchical Bento spans.
2. **Typography:** Imported Google Fonts with fluid `clamp()` sizing formulas.
3. **Multi-Layer Depth:** No flat single-layer `box-shadow`. Uses physical light diffusion.
4. **Specular Edge Highlighting:** Brighter top border mimicking an overhead light source.
5. **Tactile Haptics:** Every button scales down on click (`:active`), cards react to mouse coordinates with 3D tilt.
6. **Zero Marketing Fluff:** Technical, concrete copy with realistic domain metrics.
7. **Real Frontend Mechanics:** Filters filter instantly, modals open, toggles flip, `localStorage` saves state.
8. **Zero Alerts:** Zero `alert()` or `prompt()` calls; uses animated floating toasts.
9. **WCAG 2.1 AA/AAA Verified:** Minimum 4.5:1 relative luminance contrast for all text.
10. **100% Relative Portability:** Zero local hardcoded filesystem paths.
