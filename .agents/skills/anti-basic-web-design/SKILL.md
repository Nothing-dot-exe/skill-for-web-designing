## 🧠 1. AGENT COGNITIVE DIRECTIVES & PHILOSOPHY

Standard LLMs suffer from **statistical regression to the mean**: when prompted to construct a web UI, their training priors default to generic 3-card horizontal grids, centered purple gradient buttons, and placeholder marketing filler (*"Empower your workflow with seamless solutions"*).

**AS AN AGENT RUNNING THIS SKILL, YOU MUST EXPLICITLY OVERRIDE THESE BIASES:**
1. **Never scaffold the first predictable layout that comes to mind.** Always adopt an intentional, high-contrast **Design Archetype**.
2. **Apply Optical Alignment over Mathematical Bounding Boxes.** Human vision assesses visual weight and density, not container rects. Asymmetrical icons, badges, and rounded buttons require manual optical offsets.
3. **Layer Depth Physically.** In the physical world, light diffuses across varying elevation layers and catches specular top bevels. Never settle for a single flat CSS `box-shadow`.
4. **Every Interactive Element Must Have Real Frontend Mechanics.** No dead links, no non-functional tabs, no inert buttons. Every control must trigger state updates, animations, sound synthesis, or floating toasts.

## 🚫 2. ZERO-TOLERANCE NEGATIVE CONSTRAINTS (BANNED AI CLICHÉS)

Never generate any of the following under any circumstances:

1. **NO 3-Identical Card Grids:** Never output 3 same-sized rectangular boxes in a horizontal row with a centered circle icon and two lines of filler text.
2. **NO Generic Purple/Indigo Gradients:** Stop using `linear-gradient(to right, #6366f1, #a855f7)`. Use curated, bespoke palettes (OKLCH, electric amber, acid lime, deep alabaster, cobalt).
3. **NO AI Slop Marketing Copy:** Banned phrases:
   * ❌ *"Empower your workflow with cutting-edge solutions"*
   * ❌ *"Unlock the future of seamless productivity"*
   * ❌ *"Transform your business with intelligent technology"*
   * ✔️ *Mandate:* Write concrete, punchy, domain-specific copy with realistic technical metrics (e.g., *"Sub-5ms query latency"*, *"99.999% SLA across 32 edge regions"*, *"Zero-allocation WebAssembly pipeline"*).
4. **NO Dead Buttons / Fake UI:** Every button, tab, switch, and filter must trigger state changes, animations, toasts, or modals. Never leave `onclick=""` empty.
5. **NO Unstyled Browser Fonts:** Never rely on default system fallbacks. Always import modern Google Fonts (*Syne*, *Plus Jakarta Sans*, *JetBrains Mono*, *Space Grotesk*, *Cinzel*).
6. **NO Raw System Scrollbars:** Custom-style scrollbars with subtle translucent thumbs or hide them cleanly where appropriate.
7. **NO Flat Plain Black/White Backgrounds:** Never use pure `#000000` or `#ffffff` across an entire page without surface elevation, subtle gradients, or ambient noise.
8. **NO Native Browser `alert()` or `prompt()` Dialogs:** Replace all crude dialog boxes with custom animated floating toasts or backdrop-blurred modal overlays.

## 🎴 8. CARD ARCHITECTURE & 3D TILT PHYSICS

Cards must not be static boxes. Add perspective and reactive mouse lighting:

```javascript
// 3D Parallax Tilt Effect on Cards
document.querySelectorAll('.tilt-card').forEach(card => {
  card.addEventListener('mousemove', (e) => {
    const rect = card.getBoundingClientRect();
    const x = e.clientX - rect.left;
    const y = e.clientY - rect.top;
    const centerX = rect.width / 2;
    const centerY = rect.height / 2;
    const rotateX = ((y - centerY) / centerY) * -7;
    const rotateY = ((x - centerX) / centerX) * 7;
    
    card.style.transform = `perspective(1000px) rotateX(${rotateX}deg) rotateY(${rotateY}deg) scale3d(1.02, 1.02, 1.02)`;
    card.style.setProperty('--mouse-x', `${x}px`);
    card.style.setProperty('--mouse-y', `${y}px`);
  });
  card.addEventListener('mouseleave', () => {
    card.style.transform = 'perspective(1000px) rotateX(0deg) rotateY(0deg) scale3d(1, 1, 1)';
  });
});
```

## 🛠️ 16. CURATED AGENCY TOOLING, SQUIRCLES & WCAG MATH

### A. The Lamé Curve (Squircle Geometry)
Standard CSS `border-radius` produces abrupt curvature discontinuities where circular arcs meet straight edges. Elite designs utilize continuous superellipses:
$$\left|\frac{x}{r}\right|^p + \left|\frac{y}{r}\right|^p = 1 \quad (p \approx 4 \text{ for Apple iOS squircles})$$
Implement via SVG `clip-path` or smooth cubic bezier curvature when building premium cards.

### B. WCAG 2.1 Level AA/AAA Verification
All foreground copy against surface backgrounds must satisfy mathematical relative luminance contrast:
$$\text{Contrast Ratio} = \frac{L_1 + 0.05}{L_2 + 0.05} \ge 4.5:1 \quad (\text{AA Standard for Body Text})$$
$$\text{Large Headings / UI Elements} \ge 3.0:1$$
