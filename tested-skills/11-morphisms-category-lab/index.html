Category Theory CAT // 01

Monomorphism

fu = fv ⟹ u = v

A morphism \(f: A \to B\) that is left-cancellative. In concrete categories like \(\mathbf{Set}\) and \(\mathbf{Grp}\), monomorphisms correspond strictly to injective (one-to-one) mappings.

Left-Cancellative Injective in Set Subobject Dual
Category Theory CAT // 02

Epimorphism

uf = vf ⟹ u = v

A morphism \(f: A \to B\) that is right-cancellative. In \(\mathbf{Set}\), epimorphisms are exactly surjective (onto) mappings; in \(\mathbf{Ring}\), the inclusion \(\mathbb{Z} \hookrightarrow \mathbb{Q}\) is non-surjective yet epic.

Right-Cancellative Surjective in Set Quotient Dual
Category Theory CAT // 03

Isomorphism

f ∘ g = id_B ∧ g ∘ f = id_A

An invertible morphism possessing a unique two-sided inverse \(g = f^{-1}\). Objects with an isomorphism between them are structurally indistinguishable within the category.

Two-Sided Invertible Bijective in Set Equivalence of Form
Category Theory CAT // 04

Endomorphism

f: A → A

A morphism from an object to itself. The collection \(\mathrm{End}(A)\) forms a monoid under composition with identity \(\mathrm{id}_A\), serving as the foundational model for discrete dynamical systems.

Domain = Codomain Forms Monoid End(A) State Transition
Category Theory CAT // 05

Automorphism

Aut(A) = End(A) ∩ Iso(A, A)

An endomorphism that is also an isomorphism. Under composition, the collection \(\mathrm{Aut}(A)\) forms a group—the symmetry group of the object, encoding geometric or algebraic invariant symmetries.

Invertible Self-Map Forms Symmetry Group Galois Group Foundation
Category Theory CAT // 06

Homomorphism

ϕ(x · y) = ϕ(x) ∗ ϕ(y)

A structure-preserving map between algebraic objects (groups, rings, vector spaces). Commutes with all algebraic operations: \(\phi(e_G) = e_H\) and \(\phi(x^{-1}) = \phi(x)^{-1}\).

Operation-Preserving Kernel & Image Dual First Isomorphism Theorem
Functional Recursion Scheme FP // 01

Catamorphism (The Universal Fold)

cata(alg) : Fix(F) → A = alg ∘ fmap(cata(alg)) ∘ unfix

The generalized abstraction of recursion over inductive algebraic data structures (folds). A catamorphism is the unique homomorphism from an initial algebra to any target algebra, tearing down a data structure bottom-up into a scalar summary.

Initial F-Algebra Homomorphism Generalizes List Foldr Guaranteed Termination Structural Induction
Functional Recursion Scheme FP // 02

Anamorphism (Unfold)

ana(coalg) : A → Fix(F)

The categorical dual of a catamorphism. Generates (unfolds) potentially infinite corecursive data structures from an initial seed state via a final coalgebra.

Final Coalgebra Dual Generalizes Unfold Stream Generation
Functional Recursion Scheme FP // 03

Hylomorphism

hylo = cata(alg) ∘ ana(coalg)

An anamorphism followed directly by a catamorphism. By the Deforestation Theorem, the intermediate recursive data structure is completely optimized away at compile time without allocating memory.

Compositional Fusion Deforestation Optimization Zero Memory Heap Spikes
Functional Recursion Scheme FP // 04

Paramorphism

para : Fix(F) → A

An extension of the catamorphism modeling primitive recursion. At each deconstructive evaluation step, the algebra retains access to both the computed accumulator and the original unreduced sub-term.

Primitive Recursion Retains Sub-Term Context Factorial & Tails
Functional Recursion Scheme FP // 05

Apomorphism

apo : A → Fix(F)

The dual of a paramorphism. Models corecursive unfolding with short-circuiting: at any step, the coalgebra can choose to immediately terminate recursion by emitting an existing sub-tree.

Short-Circuit Unfold Early Exit Corecursion Stream Insertion
Algebraic Geometry GEOM // 01

Étale Morphism (Local Isomorphisms)

f: X → Y is Étale ⟺ Flat ∧ Unramified (Ω_{X/Y}^1 = 0)

The algebraic geometry analogue of local biholomorphisms or smooth unbranched covering spaces in differential topology. An étale morphism has zero differential sheaf (\(\Omega_{X/Y}^1 = 0\)) and flat fibers, serving as the basis for Grothendieck's Étale Cohomology.

Flat + Unramified Algebraic Covering Map Étale Site (Grothendieck) Weil Conjectures Proof
Algebraic Geometry GEOM // 02

Flat Morphism

Tor_1(O_X, -) = 0

A morphism where fibers vary continuously without sudden dimensional jumps or algebraic catastrophes. Makes the structure sheaf \(\mathcal{O}_X\) a flat module over \(\mathcal{O}_Y\).

Continuous Family No Fiber Jumps Hilbert Schemes Foundation
Algebraic Geometry GEOM // 03

Proper Morphism

Universally Closed ∧ Separated

The scheme-theoretic analogue of compact Hausdorff mappings in topology. Remains closed under arbitrary base change (\(X \times_Y Z \to Z\) is closed for all \(Z\)), satisfying the Valuative Criterion of Properness.

Universally Closed Valuative Criterion Compactness Analogue
Algebraic Geometry GEOM // 04

Smooth Morphism

Flat ∧ Smooth Fibers (Rank J = Dim)

The algebraic analogue of differential submersions. A flat morphism whose geometric fibers are all non-singular varieties of constant dimension, satisfying the infinitesimal lifting criterion.

Submersion Analogue Locally Trivial Topology Deformation Invariance
